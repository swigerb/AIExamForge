Item Type: Drag and Drop (DD)

Purpose:
Assess ability to correctly place objects within a system or diagram.

Rules:
- Answer sources: minimum 3, maximum 8.
- Targets: minimum 2, maximum 5.
- Empty targets are NOT allowed.
- Instruction must specify whether sources:
  - Can be reused
  - Can be unused
- Each correct placement earns one point (polytomous scoring).

Output Requirements:
- Define sources, targets, and placement rules.
- Return JSON that conforms to the DD schema.
