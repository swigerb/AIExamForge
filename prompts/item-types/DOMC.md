Item Type: Dynamic Option Multiple Choice (DOMC)

Purpose:
Evaluate multiple possible solutions to the same problem independently.

Structure:
- One shared problem statement.
- Multiple solution variations.
- Each variation asks: “Does this meet the goal?” with Yes/No answers.

Rules:
- Each DOMC set must contain:
  - At least 1 correct solution
  - At least 3 incorrect solutions
- Learners see ONLY 3 randomly selected solution variations per delivery.
- Learners must NOT be allowed to navigate back once they advance.
- DOMC items must appear last in an assessment.
- Each SET counts as a single item worth 1 point.

Output Requirements:
- Generate a DOMC set object containing multiple solution variants.
- Each variant must map to the same problem statement.
- Return JSON that conforms to the DOMC schema.
