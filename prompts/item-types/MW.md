Item Type: Magnetic Words (MW)

Purpose:
Assess ability to construct code by arranging code fragments.

Rules:
- Provide 6–12 code blocks.
- Learner must arrange 3–5 blocks into correct order.
- Instruction text must specify how many blocks are required.
- Each correct action earns one point (polytomous scoring).

Output Requirements:
- Code blocks must simulate a real-world coding environment.
- Return JSON that conforms to the MW schema.
