Item Type: Multiple-Alphabetic / Choose-N (M2, M3, …)

Purpose:
Assess ability to select exactly N correct answers.

Rules:
- The stem MUST specify the exact number of answers to select.
- “Choose all that apply” MUST NOT be used.
- Minimum answer choices:
  - M2: at least 4 choices
  - M3: at least 5 choices
- Author must specify whether:
  - Each correct answer represents a PARTIAL solution, OR
  - Each correct answer represents a COMPLETE solution
- Polytomous scoring: each correct selection earns a point.

Output Requirements:
- Explicitly include requiredSelectionCount.
- Return JSON that conforms to the Choose-N schema.
