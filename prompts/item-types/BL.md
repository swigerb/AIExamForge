Item Type: Build List (BL)

Purpose:
Assess ability to identify and correctly order procedural steps.

Rules:
- Use ONLY when the order of actions is critical.
- Minimum 3 steps; maximum 5 steps.
- If more than 2 valid orderings exist, use a different item type.
- Up to 2 valid solutions may be defined using the same steps.
- Instruction statement MUST specify the number of steps to move.
- Polytomous scoring:
  - Correct steps earn points
  - Correct order earns points

Output Requirements:
- Return ordered step lists and valid solutions.
- Return JSON that conforms to the BL schema.
