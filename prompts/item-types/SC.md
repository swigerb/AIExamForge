Item Type: Sentence Correction (SC)

Purpose:
Assess whether underlined text in a sentence makes the statement accurate.

Rules:
- Include “No change is needed.” as the FIRST answer choice.
- Exactly 1 answer choice is correct.
- At least 2 distractors must be provided in addition to “No change is needed.”
- Answer choices MUST NOT be randomized.
- An instruction statement MUST precede the question.
- Do not include teaching text or explanations in the sentence or answer choices.

Output Requirements:
- Identify the underlined portion in the sentence.
- Return JSON that conforms to the SC schema.
