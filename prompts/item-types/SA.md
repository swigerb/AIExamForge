Item Type: Short Answer Code (SA)

Purpose:
Assess ability to write code or commands.

Rules:
- Learner enters code into a free-text field.
- Syntax checking may be allowed (not correctness).
- Provide all required names, values, and context in stem or exhibits.
- Constraints:
  - Maximum 10 lines total
  - Average 4–6 lines
  - No more than 5 code elements per single-line command
  - No more than 4 lines for multi-line commands
- Multiple correct answer variants may exist.
- Polytomous scoring based on complexity.

Output Requirements:
- Return JSON that conforms to the SA schema.
